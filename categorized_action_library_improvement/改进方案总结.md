
  - ✅ 窗口缩放时不重叠

## 💡 关键技术点

### 1. 布局架构变化

**原架构:**
```
QTabWidget (West)
├── Tab 1 (旋转90°)
├── Tab 2 (旋转90°)
└── Tab 3 (旋转90°)
```

**新架构:**
```
HBoxLayout
├── QListWidget (类别列表,180px宽)
│   ├── CustomItem: [Icon] Text
│   ├── CustomItem: [Icon] Text
│   └── CustomItem: [Icon] Text
└── QStackedWidget (内容页面,自适应)
    ├── Page 1
    ├── Page 2
    └── Page 3
```

### 2. 图标渲染流程

**方案1 (Emoji):**
```
Emoji → QLabel.setText() → 系统字体渲染 → 显示
```

**方案2 (QIcon):**
```
Emoji → QPainter绘制 → QPixmap → 缓存 → 显示
```

### 3. 响应式设计要点

```python
# 关键设置:
icon_label.setFixedSize(64, 64)      # 固定容器,防止溢出
name_label.setWordWrap(True)         # 长文本自动换行
name_label.setMinimumHeight(30)      # 保证最小显示空间
desc_label.setWordWrap(True)         # 描述文字自适应
```
